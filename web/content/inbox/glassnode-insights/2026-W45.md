glassnode API UPDATE

******************************
When does a data point arrive?
******************************

Hi there,

Every data point we publish is the result of a computation. Once the interval ends, the metric gets computed. The time this takes is the computation lag, and we now expose it through a new metadata endpoint.

The p50 value is the average time it takes for a data point to arrive. We also provide further percentiles like the p99, which means that 99 out of 100 data points arrive faster than this.

Timeline: the 08:00 hourly close covers 08:00 to 09:00 and arrives a few minutes after 09:00

This is relevant when you fetch data periodically with cron jobs, or when you run local backtests and want to account precisely for the delay.

----------------------
How to fetch this data
----------------------

Let's say we want to know the computation lag of the BTC close price on the hourly time series. We pass the metric path and the asset to the metric stats endpoint:

https://api.glassnode.com/v1/metadata/metric/stats?path=/market/price_usd_close&a=BTC

The response holds the percentiles for every resolution. For the hourly series:

RESOLUTION P50 P90 P95 P99
1h 3.8 min 5.2 min 5.2 min 7.2 min
